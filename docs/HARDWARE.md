# アーム接続の確認

## 確認できたこと

- 接続中の基板はArduino公式CLIで `Arduino UNO / arduino:avr:uno` と照合できた。
- THINKLET CubeはCamera2で320×240のカラー映像を取得し、露出固定に対応している。
- 今回のキットのメーカー・サーボの配線はUSB記述子から取得できない。
- `basic robokit2` の表記で公式製品ページ・専用ライブラリは特定できていない。公式URLの提示待ち。

## 暫定ファームウェアの適用条件

`arduino/brightness_arm/` はArduino公式 [Servoライブラリ](https://github.com/arduino-libraries/Servo)を使う、PWM位置制御サーボ1軸用。
DCモーター、連続回転サーボ、バスサーボ、専用コントローラ式のアームにはそのまま適用しない。

設定例のD9・70°・110°・90°は仮の値。アームの信号ピン、機械的に干渉しない可動範囲、開始角度を確認して設定する。
サーボ電源はキット指定の電源を使い、Arduinoと信号のGNDを共有する。基板のUSB認識だけではモーター電源を確認できない。

## 動作確認の流れ

1. 製品の公式仕様と実際の配線を照合する。
2. 専用ファームウェアを書き込む。起動時にはサーボを接続せず、出力を開始しない。
3. 操作ボードで配線・可動範囲を保存し、Arduino接続を選ぶ。専用プロトコルの応答で接続を確認する。
4. 「制御を有効にする」を選ぶと開始角度を出力する。手動の上下を先に確認する。
5. 「明るさに連動させる」を選ぶ。カメラを覆う／戻すことで上下の判断と動作を確認する。

停止ボタン・通信監視は移動指令を止め、最後のサーボ角度指令を保持する。モーター電源を切る機能ではない。
カメラのフレームが1.5秒以上古くなった場合は制御を停止し、Arduinoは1.2秒以上指令が途切れた場合に移動を止める。
実際のアーム位置、停止、重力による落下の有無は目視または追加センサーで確認する。

## 通信

115200bps、改行区切り。`HELLO` に `READY PHYSICAL_AI_ARM_V1` が返ることを確認する。
`ARM pin min max home`、`TARGET angle`、`PING`、`STATUS`、`STOP` に対応。
状態は `STATE armed commanded target pin min max` として返す。角度は計測した実位置ではなく、サーボの出力指令。

## 開発機のコンパイルについて

このMacではArduino公式AVRツールチェーンのコンパイラがIntel用のため、ローカルコンパイルは `bad CPU type in executable` で停止した。
GitHub ActionsのLinux環境でUno用コンパイルを実施する。Mac全体の設定変更やRosettaのインストールは行っていない。
